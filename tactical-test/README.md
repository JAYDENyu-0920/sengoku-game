# 戰國群雄錄 D8-A2 戰法與軍令測試版

D8-A1 戰前編制功能保留。新增軍令（雙方開局 3、每完整輪 +2、上限 5）與騎馬突擊、齊射、堅守。槍衾已建立技能資料，但反應戰法操作尚未接入 D7 反應視窗，不應視為已完成。戰術卡留待 D8-A3。

注意：騎馬突擊須先移動至少兩步；齊射限弓兵；堅守降低所受傷害 20%。所有技能指令在引擎檢查軍令及兵種。部署到 GitHub tactical-test/，勿覆蓋根目錄 index.html。

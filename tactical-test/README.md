# 《戰國群雄錄》B1 V4.0-D1 — iPhone Safari 戰棋試玩版

## 開啟方法

請使用 HTTP 伺服器開啟，不能直接點開 `file://index.html`（ES Modules 受瀏覽器安全限制）。

在資料夾中執行：

```bash
python3 -m http.server 8000
```

接著在同一台電腦瀏覽器開啟 `http://localhost:8000/`。若要用 iPhone 測試，請在同一個 Wi-Fi 下使用電腦的區網 IP，例如 `http://192.168.x.x:8000/`；電腦防火牆需允許連線。

也可將整個資料夾部署至靜態網站（例如 GitHub Pages 的獨立測試路徑），**不要覆寫原本的大地圖首頁**。

## D1 可操作範圍

- 10×10 六角格、示範地形、雙方各三隊
- 觸控選取部隊、交替啟動、可達格移動
- 普通攻擊、基本傷害與士氣、鐵砲裝填
- 敵軍反應窗口（目前 UI 僅提供「放棄反應」）
- 回合與基本勝敗、戰鬥紀錄、重新開始

## 已知限制

- **D1 為雙方手動操作的示範戰場**，尚未接入 AI 自動操作；可在同一裝置輪流操作攻守雙方。
- 移動採引擎產生的最短合法路徑，尚不能自行逐格指定路徑。
- 目前不提供戰術卡、撤退按鈕、部隊面向、武將技能或正式迷霧介面。
- 無 IndexedDB 保存，重新整理網頁會重新開始示範戰役。
- 沒有大地圖存檔或永久結算整合，完全不會修改既有戰略存檔。
- 引擎仍為 C8 開發版本，部分數值與規則尚未最終封版。

## 自動化測試

```bash
node --test *.test.mjs
```

測試覆蓋原有 C1–C8 引擎；D1 的觸控畫面仍需 iPhone Safari 實機驗收。

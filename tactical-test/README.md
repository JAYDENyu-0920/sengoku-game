# 戰國群雄錄 V4.0-D6

基於 D5 實機驗收版本。新增攻擊前傷害區間與敵軍預估剩餘兵力（依目前傷害公式 0.9～1.1 隨機倍率，無消耗 RNG）；攻擊後在受擊部隊上方顯示飄字；AI 優先選擇可擊潰敵軍及主將。保留 D5 相剋規則。

注意：攻擊預覽只涵蓋現有普通攻擊公式，不保證移動途中反應後的結果；飄字非完整移動動畫；AI 尚未實作正式兩步搜尋；戰術卡抽選介面仍未完成。

部署：解壓縮後把檔案上傳至 GitHub `sengoku-game/tactical-test/`，覆蓋同名檔案。不要覆蓋根目錄的 `index.html`。

測試：`node --test *.test.mjs`。


## D6.1 玩家傷害飄字修正
玩家確認攻擊後，`send()` 會先重繪地圖並建立傷害飄字；原先事件處理器又呼叫 `render()`，使 SVG 飄字立即被清空。D6.1 移除這次重複重繪，保留 AI 攻擊的原有流程與傷害公式。


## D7 反應決策介面
- 當敵軍移動觸發我方反應時，自動顯示決策視窗，列出所有合法的我方反應部隊。
- 點選任一部隊執行 `CHOOSE_REACTION`；選擇放棄則執行 `PASS_REACTION`，保留尚未使用的反應機會。
- 敵方 AI 反應沿用 D6 既有邏輯。
- 反應途中會暫停一般地圖操作，處理完後恢復。
- 未實測 iPhone Safari；請在觸發反應時驗收選項與行動是否可用。

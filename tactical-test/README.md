# 戰國群雄錄 V4.0-D4（單人 AI 測試版）

獨立 tactical-test 測試場景；不修改原本大地圖與存檔。

## 本次更新
- 玩家藍色攻方、AI 紅色守方（固定普通難度）。AI 依可見敵軍做簡單移動、攻擊、裝填與結束行動。
- 選取我方未行動部隊不再立刻 ACTIVATE_UNIT；可以自由切換選取並取消前一支的暫定移動。
- 真正攻擊或按結束行動才提交 ACTIVATE_UNIT；已提交後須先完成該部隊行動，符合交替啟動規則。
- 保留 D3 暫定移動、取消移動、可行動綠色圈與已行動勾號。

## 已知限制
- AI 為啟發式基本對手，並非完整兩步搜尋；目前使用全場敵軍可見的示範情報，尚未實作正式戰爭迷霧。
- AI 反應攻擊為簡易合法性判斷，可能放棄反應。
- 若玩家需要回應 AI 移動引發的反應窗口，仍可使用「放棄反應」；目前尚無完整玩家反應選擇 UI。
- 尚未於 iPhone Safari 真機驗證，請以實機測試為準。

## 部署
將 ZIP 解壓縮後所有檔案上傳到 GitHub 專案的 `tactical-test/`，覆蓋同名檔案，**不要覆蓋根目錄 index.html**。GitHub Pages 網址為 `/sengoku-game/tactical-test/`。

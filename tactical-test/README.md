# 戰國群雄錄 B1 V4.0-D3｜操作提示與暫定移動

D2 基礎上的獨立戰棋測試版。請將**整個資料夾內的檔案**上傳至 GitHub `sengoku-game/tactical-test/`，覆蓋該資料夾中的同名檔案；**不要覆蓋專案根目錄 `index.html`**。GitHub Pages 部署後開啟 `https://jaydenyu-0920.github.io/sengoku-game/tactical-test/`。

- 當前可行動部隊以綠色虛線外圈提示；戰場狀態列顯示尚可行動隊數。
- 點選部隊立即啟動、顯示合法移動格；點選目的地只產生本機**暫定移動**，可再次改選或取消移動，並不寫入引擎、觸發敵方反應或更動戰報。
- 確認攻擊或結束部隊行動時，先正式提交暫定移動；若引擎開啟敵軍反應窗口，會暫停後續指令，不會偷偷跳過反應。
- 攻擊一旦確認即結算且無法回溯。已正式移動也不能撤銷。D2 的 2.7 倍傷害係數保留。

**限制**：本版是前端的暫定位置預覽，不是戰鬥引擎層的交易／撤銷系統；未完成敵方反應選擇、AI、戰術卡完整整合與永久存檔。iPhone 實機尚待使用者驗收。

測試：`node --test *.test.mjs`。
